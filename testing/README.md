# Тестирование «Лампады»

Задачи, их статусы, исполнители и дефекты ведутся в ClickUp. Корневая задача:
[«Организовать проверку качества Lampada»](https://app.clickup.com/t/86cb8k50b).

Репозиторий хранит только версионируемые материалы, необходимые для
воспроизведения и проверки результата:

- [`TEST_PLAN.md`](./TEST_PLAN.md) — идентификаторы сценариев и ожидаемое поведение;
- `e2e/` — исполняемые Maestro-сценарии;
- `reports/` — датированные неизменяемые результаты прогонов;
- `evidence/` — отобранные доказательства, на которые ссылаются отчёты.

Здесь не дублируются текущие статусы задач и локальные `BUG-*.md`. Новый дефект
создаётся в ClickUp как подзадача типа `Bug` у этапа, на котором он найден.
Исправленный и перепроверенный дефект закрывается там же. Отложенный или
осознанно принятый дефект переносится в этап `99`.

## Запуск smoke

Сначала соберите и запустите приложение способом, описанным в корневом
[`README.md`](../README.md). Expo Go не является валидным окружением: проект
использует отсутствующие в нём нативные модули.

Полный smoke и отдельная проверка сохранности после перезапуска:

```bash
maestro test testing/e2e/ios-smoke-full.yaml
maestro test testing/e2e/ios-smoke-full-relaunch.yaml
```

Первый завершённый прогон описан в
[`reports/2026-08-21-ios-simulator-smoke.md`](./reports/2026-08-21-ios-simulator-smoke.md).

## Доказательства

В репозитории остаются только финальные скриншоты, решающие логи, снимки данных
и сводка exit codes. Повторные попытки, полные системные/Xcode-логи, дубли crash
reports и артефакты сборки хранятся вне репозитория или в CI. Подробные правила:
[`evidence/README.md`](./evidence/README.md).
