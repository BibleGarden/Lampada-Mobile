## Repairs verified by this run

- **Share:** the outside tap and a drag did not dismiss the native popover.
  The flow now uses its observed accessibility dismissal action, then verifies
  the journal and Share button remain available. It passed in isolation,
  rare and the full journal suite.
- **Languages:** exact standalone names did not match combined picker labels.
  Assertions now bind both the picker ID and its actual language text.
  Locale settings are written while the simulator is booted, then it is
  restarted. The runner stops on failure and restores both the system locale
  and the app interface language to Russian. This prevents English UI from
  leaking into subsequent PIN checks.
- **PIN cleanup:** wrappers depended on absent `/tmp/disable-pin.yaml` and
  suppressed its failure. The tracked `ios-lock-cleanup.yaml` removes the
  known test PIN and verifies that protection is disabled. Cleanup errors
  propagate. The reminder editor then passed.
- **App Switcher:** the old AppleScript targeted an obsolete Simulator menu.
  The runner now separates preparation, capture and cleanup. Device Hub's
  Home control opened App Switcher; the actual snapshot was inspected.
  Capturing alone is not an automatic privacy assertion.
- **Biometrics:** the old enrollment post did not register Touch ID. Explicit
  notification state `com.apple.BiometricKit.enrollmentChanged` 1/0 works.
  The native probe returned Touch ID type 1, initially error -7 (not enrolled),
  then successful policy evaluation: `native-before.json` and
  `native-enrolled.json`. Hardware was present; the earlier apparent
  unavailability was caused by runner setup.
- **Native biometric prompts:** they cover the app accessibility tree. Flows
  now wait for the native dialog, and the runner sends a match only once the
  flow has reached its recorded wait. A mismatch leaves the iOS retry prompt
  open; the test verifies that feedback, selects its PIN action, rejects the
  wrong code and accepts the correct one. Redundant confirmation and stale
  PIN-dialog IDs were removed from cleanup.
- **Favorite persistence:** the obsolete combined SCR-002 duplicate was
  removed. Active SCR-002a/b flows reset the stub counter between prayers
  and passed persistence and deletion checks.

Intermediate attempts remain in raw artifacts and are indexed in
`results.json`, including nonzero exits. One suite attempt was disrupted by
editing a running Bash file; the final suite ran on frozen source and passed.
No failed invocation was used as evidence of success.
