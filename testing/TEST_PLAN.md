# Тест-план Twinkler

- Назначение: версионируемый каталог сценариев; статусы выполнения ведутся в ClickUp
- Продукт: Expo SDK 57 / React Native, iOS и Android
- Основная платформа первого прогона: iOS, собственная Release-сборка

## Источники правды

- [корневая задача ClickUp](https://app.clickup.com/t/86cb8k50b) — этапы,
  исполнители, статусы выполнения и дефекты;
- этот тест-план — стабильные ID сценариев и ожидаемые результаты;
- `reports/` — датированные результаты конкретных прогонов;
- `evidence/` — отобранные подтверждения, на которые ссылаются отчёты.

Текущие статусы сценариев в этом файле не хранятся.

## 1. Цель

Проверить, что пользователь может пройти полный цикл молитвы без потери данных:

1. открыть приложение;
2. выбрать цель и длительность;
3. начать молитву удержанием кнопки;
4. отвечать текстом и голосом, читать и сохранять места Писания;
5. завершить молитву и сохранить вывод;
6. найти результат в дневнике после перезапуска приложения.

Дополнительно проверить устойчивость при отказе микрофона, сети и ИИ, корректность
локального хранения и отсутствие неожиданной отправки пользовательских данных.

## 2. Вне объёма первого прогона

- качество богословских формулировок ИИ оценивается отдельно человеком;
- нагрузочное тестирование серверного AI-прокси;
- публикация и обновление через App Store / Google Play;
- исчерпывающая проверка всех версий iOS и Android.

## 3. Главные риски

| Приоритет | Риск | Что проверяем |
|---|---|---|
| P0 | Потеря ответа или записи | сохранение при закрытии шторки, окончании таймера и перезапуске |
| P0 | Падение или тупик в основном потоке | переходы `setup → threshold → session → reflect → done` |
| P0 | Нарушение приватности | настройку передачи ответов, тело AI-запроса, локальность аудио |
| P1 | Ошибки нативных модулей | Skia, Reanimated, Gesture Handler, SQLite и Expo Audio в собственном билде |
| P1 | Ошибки таймера | фон/передний план, изменение времени, авто- и досрочное завершение |
| P1 | Повреждение дневника | поиск, детали, воспроизведение и каскадное удаление |
| P1 | Недоступность ИИ | отсутствие конфигурации, тайм-аут, HTTP-ошибка, пустой ответ |
| P2 | Ошибки календаря | серия дней, повторное завершение в один день, граница суток и часовой пояс |
| P2 | Проблемы интерфейса | маленький экран, iPad, клавиатура, safe area, длинные тексты |

## 4. Окружения

### Обязательные для первого прогона

| Окружение | Назначение |
|---|---|
| Собственный iOS Release-билд на физическом iPhone | основной пользовательский прогон, микрофон, звук, хаптика, сохранение после перезапуска |
| iOS Simulator | быстрые повторные проверки экранов, навигации и размеров |
| Проверки исходного кода | TypeScript и диагностика совместимости Expo SDK |

### Следующий этап

| Окружение | Назначение |
|---|---|
| Android Emulator и физическое устройство | системная кнопка «назад», разрешения, запись и воспроизведение |
| iPad / iPad Simulator | `supportsTablet`, portrait layout, ширина и масштабирование |
| Web | только smoke-проверка, если web является поддерживаемой платформой продукта |

Для каждого отчёта фиксируются модель устройства, версия ОС, commit, тип сборки,
наличие AI-конфигурации и состояние базы до начала прогона.

## 5. Наборы тестовых данных

- чистая установка без записей и настроек;
- установка с одной завершённой молитвой;
- история из 20+ молитв с похожими русскоязычными целями;
- пустая, короткая и очень длинная цель, кириллица, emoji и переносы;
- молитва без таймера, на 5 минут и с изменённым в процессе таймером;
- ответы: пустой, только пробелы, длинный текст, несколько аудиозаписей;
- AI выключен, работает, отвечает медленно и возвращает ошибку;
- разрешение микрофона выдано, отклонено и ранее запрещено в настройках ОС.

## 9. Нефункциональные проверки

### Интерфейс и доступность

- экраны 320–430 pt по ширине, iPhone с Dynamic Island и без него;
- iPad в поддерживаемой portrait-ориентации;
- клавиатура не закрывает поле и основные действия;
- длинные русские строки не обрезаются критически;
- кнопки имеют достаточную область нажатия и понятные accessibility labels;
- увеличенный системный текст, VoiceOver/TalkBack, Reduce Motion;
- контраст текста, состояний toggle и подтверждения удаления.

### Надёжность и производительность

- холодный старт без белого/зависшего экрана;
- отсутствие заметных зависаний анимации таймера и пламени;
- отсутствие роста памяти после 10 открытий шторок и воспроизведений;
- корректность после background/foreground, блокировки экрана и системного звонка;
- отсутствие незакрытых таймеров, записи микрофона и аудиоплеера после ухода с экрана.

### Безопасность и приватность

- Google/server master key отсутствует в клиентском бандле и логах;
- клиентский proxy key рассматривается как публичный и ограниченный;
- текст ответов отправляется только при включённой настройке;
- аудиофайлы хранятся в ожидаемой директории и отправляются в endpoint расшифровки только после явного нажатия;
- серверные логи и постоянное хранилище не содержат аудио, имени файла и расшифровки;
- логи не содержат молитвенные ответы, токены и полные сетевые payload;
- системное описание разрешения микрофона соответствует реальному использованию.

## 11. Классификация дефектов

| Severity | Значение |
|---|---|
| Critical | потеря/утечка данных, падение на основном сценарии, невозможность запустить приложение |
| Major | основной сценарий нельзя завершить без обходного пути; неверно сохраняются данные |
| Minor | функция работает с заметным дефектом или неудобством, есть простой обход |
| Trivial | косметическая проблема без влияния на выполнение сценария |

Приоритет исправления (`P0–P3`) назначается отдельно от severity с учётом частоты
и ценности сценария.

## 12. Критерии завершения первого прогона

Прогон завершён, когда:

- выполнены все `PRE`, `SMK` и функциональные сценарии первого iOS-окружения;
- для каждого сценария указан `Passed`, `Failed`, `Blocked` или `Not run`;
- у каждого `Failed` есть ClickUp Bug под соответствующим этапом и доказательство;
- нет открытых Critical-дефектов;
- Major-дефекты разобраны и имеют решение либо явное продуктовое принятие риска;
- зафиксированы ограничения покрытия Android, iPad, accessibility и background;
- итоговый отчёт содержит версии, commit, exit codes и полные логи проверок.
