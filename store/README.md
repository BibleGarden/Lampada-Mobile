# App Store materials

`screenshots/` holds the App Store Connect screenshots, named
`<device>-<language>-<NN>-<screen>.png`:

- devices: `iphone-6.9` (iPhone 6.9″ display), `ipad-13` (iPad 13″ display);
- languages: `en`, `ru`, `uk`;
- screens: `01-home`, `02-topic`, `03-question`, `04-answer`, `05-audio`,
  `06-passage`, `07-reflection`, `08-history`.

They are captured on the `Lampada AppStore UK iPhone 17 Pro Max` and
`Lampada AppStore iPad Pro 13` simulators (see `AGENTS.md`). Retake them after
visible interface changes and replace the files in place.

Current set: taken on 2026-09-20, before the 2026-09-22/23 accessibility changes
(text colours, consent dialog sizes).
